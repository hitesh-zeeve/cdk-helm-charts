To verify the installation:

1. Check ESO pods:
   kubectl get pods -n external-secrets

2. Verify ServiceAccount has IRSA annotation:
   kubectl get sa {{ index .Values "external-secrets" "serviceAccount" "name" }} -n external-secrets -o yaml
   
   Should show:
     annotations:
       eks.amazonaws.com/role-arn: arn:aws:iam::<account>:role/<name>

3. Check ClusterSecretStore status:
   kubectl get clustersecretstore aws-secretsmanager
   kubectl describe clustersecretstore aws-secretsmanager

   The ClusterSecretStore should show status "Valid: True" when ready.

Troubleshooting:

- If ClusterSecretStore is not Valid, check ESO logs:
  kubectl logs -n external-secrets -l app.kubernetes.io/name=external-secrets

- If ServiceAccount is missing IRSA annotation, the External Secrets Operator
  may not have been installed with the correct configuration. Reinstall with:
  
  helm upgrade external-secrets external-secrets/external-secrets \
    -n external-secrets \
    --set serviceAccount.annotations."eks\.amazonaws\.com/role-arn"="arn:aws:iam::ACCOUNT:role/NAME"
